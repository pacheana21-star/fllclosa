💻¿Cuáles son los beneficios de la banca en línea? • Personalización de sus productos para su fácil identificación. • Afiliación automática de todos sus productos para tener toda su información financiera a la mano. • Registro de cuentas como favoritas para fácil acceso en futuras transacciones. • Autorización de transacciones por medio de token para brindar mayor seguridad. • Registro de transacciones recurrentes para agilizar pagos y transferencias frecuentes. • Una pantalla de inicio que le brindará consultas rápidas de saldos, últimas transacciones, tasa de cambio y acceso a transacciones frecuentes. • Fácil acceso a las transacciones históricas de todos los productos afiliados.
✏️Olvide mi contraseña ¿Cómo la puedo recuperar? Después de 3 intentos se bloqueará tu usuario. Ahora puedes obtenerla de forma sencilla y rápida la contraseña 1. Ingresa a ¿Has olvidado tu contraseña? 2. Selecciona el tipo de mecanismo para autorizar tus transacciones *Token (VU o token integrado) *SMS token (Token mensaje de texto) 3. Ingresa tu usuario y correo electrónico 4. Ingresa el token generado !Listo! Recibirás tu contraseña temporal Después podrás realizar el cambio de contraseña *Utiliza letras y números *Utiliza al menos una mayúscula *Utiliza al menos 12 caracteres Al cambiar la contraseña se te solicitará ingresar nuevamente.
🔑 ¿Qué es un token integrado? Es un código de seguridad que funciona desde la app de Ficohsa. El token para transacciones en la App al estar registrado se autorellena sin necesidad de esperarlo por otra vía. El token en la App Ficohsa te permitirá realizar transacciones en la banca web sin esperar el token por otra vía. Puedes visualizarlo dentro de la misma App Ficohsa.
🔑¿Cómo configuro mi app para utilizar token integrado? 1. Ingresa al menú Más en tu app o desde el Banner de Registro 2. Ingresa a Token 3. Selecciona la opción Activar Token 4. **Si ya tienes registrado tu dispositivo como seguro, al darle clic en código de activación se abre una ventana, clic en Continuar **Si No tienes registrado tu dispositivo, recibirás un sms con tu código de activación, si no lo recibes puedes solicitar otro 5. Ingresa una contraseña de 6 números que te servirá para ver tus tokens y utilizarlos en la web ¡¡¡Listo te haz Registrado!!!
😓 Olvidé mi contraseña de Token 1. Ingresa a la app 2. Ingresa al botón MAS 3. Ingresa a Token 4. En la casilla donde aparecen los token en el lado superior derecho hay 3 puntos, clic ahi 5. Se abre una pestaña con la opcion de *Cambiar Contraseña de Token* 6. Ingresa la nueva contraseña y Listo
☝️🤓Como utilizo mi token de la App en la Web? 1. Abre la app, pero no ingreses 2. En la barra donde están los íconos de Inicio, ubícanos, esta el ícono de un candado, da clic 3. Aparece un cuadro con tu usuario, y una frase en azul que indica -Mostrar Token- da clic 4. Ingresa tu contraseña de token 5. Ya puedes gestionar en la web
🚫Mi usuario está bloqueado ¿Cómo lo puedo recuperar? 1. Ingresa ¿Tu usuario ha sido bloqueado? 2. Coloca tu usuario y correo electrónico 3. Ingresa el token enviado por correo 4. Listo, se ha desbloqueado tu usuario
